How the numbers were worked out

  • Developed: the date the skill or agent file was first written, checked against Claude session logs.
  • Build time: an estimate of hands-on time in each session.
    • Counts active minutes from your first request to the last change.
    • Breaks longer than 5 minutes are capped at 5 minutes.
  • Not counted: time spent using a build after it was finished.
    • For example, publishing reports or doing job scans.
    • Supporting pieces built separately, such as the speed-test collector (about 45 min, 19 to 25 Aug).
  • Shared sessions: some builds were made together, so their time is split.
    • Interview Prep Agent, Company Interview Brief and Interview Brief Web Report: 28 and 29 Sep, about 1h 50m.
    • New GitHub Site and Update Live Site: about 20 min together.
  • Portfolio website: time covers the personal brand sessions, 26 Jul to 10 Sep.
    • Includes small related pieces: a role-themes diagram and a Data Strategy & Evolution link.
    • Treat it as within plus or minus 30%.
  • ACCA Seat Planner: time covers the Claude Code sessions, 12 to 16 Oct.
    • Versions 1 to 17 were built earlier in a claude.ai chat; that time is not counted.
    • Use is not tracked: the app runs on each coach's phone with no analytics.
  • ChatGPT builds: dates, results and obstacles come from your ChatGPT inventory (18 Oct).
    • Build dates are when the related chat was created.
    • Build time was not recorded.
  • Results and obstacles: counts come from output folders, run logs, trackers and GitHub, as at 18 Oct.
    • Obstacles are problems raised in build sessions, and how each was handled.
  • Status: set by Adam, as at 19 Oct 2026.
  • Times used and run time: counted from session logs and scheduled and cloud run history, to 18 Oct.
    • A use is one slash command or scheduled run.
    • Run time is Claude's working time, not time spent waiting on you.
    • Portfolio views come from GoatCounter.
    • ChatGPT counts assume one use a day and have not been checked.
  • Version updates: how many times each build changed after it was first built.
    • Counted as separate editing sessions in the session logs.
    • The portfolio and seat planner use their published version history.
    • ChatGPT figures come from your inventory.
  • Precision: figures are rounded to the nearest 5 minutes. Treat them as within plus or minus 25%.
